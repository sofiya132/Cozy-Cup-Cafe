# Cozy Cup Cafe ☕

*"Life happens, coffee helps."*

A responsive multi-page cafe website built with HTML, CSS and JavaScript. Visitors can browse the menu by category, add items to a cart and get in touch with the cafe.

**Live demo: [cozy-cupcafe.netlify.app](https://cozy-cupcafe.netlify.app/)**

## Pages

- **Home**: welcome screen with the cafe's tagline
- **About**: the story behind the cafe
- **Menu**: three categories (Coffee, Tea, Snacks and Puffs)
- **Cart**: items you've added, with a live item counter in the navigation bar
- **Login**: sign-in page
- **Contact**: ways to reach the cafe

## Features

- Multi-page navigation with a shared header and footer
- Responsive layout that works on phones, tablets and desktops
- Menu organised into categories
- Cart with a live item counter
- Clean, organised file structure

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

Visit the live demo above, or run it locally:

```bash
git clone https://github.com/sofiya132/Cozy-Cup-Cafe.git
cd Cozy-Cup-Cafe
```

Then open `index.html` in any modern web browser.
